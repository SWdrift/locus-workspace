# 冻结归档

这些 Agent Note 是冻结的历史快照，不是当前行为的权威依据。遵循 [决策记录规范](../AGENTS.md#文件格式)与[归档与删除](../AGENTS.md#归档与删除)。

归档时只允许移动记录、保留 `Status: implemented`、紧接状态行插入 `Archived: YYYY-MM-DD`，以及修复或删除活动文档中的入站链接。封存后禁止编辑、翻译、重排、更新、修补出链、移动或删除；即使其中的路径或参数已经过时，也保留封存时的正文。

新决定和新事实写入活动记录或当前文档，不写回归档。活动文档可以链接归档以引用历史，但不得把归档内容当作当前契约。

`pnpm docs:check` 只验证归档记录的身份元数据、归档日期位置和类别目录，跳过正文结构、围栏和旧出链；活动页指向归档的链接仍检查目标与锚点。归档冻结依靠审阅和版本历史，没有哈希封存或版本历史级追加保护。

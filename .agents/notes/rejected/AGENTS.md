# 已否决记录

这些 Agent Note 是冻结的否决提案，结论写在状态行。遵循 [决策记录规范](../AGENTS.md#文件格式)。

`Status:` 行必须为 `Status: rejected — 一行拒绝理由`，理由写清否决的核心约束。记录保留提案时的正文，包括 `提案`、`验收标准`、`风险` 等章节；不为套用其他模板删除原有内容。`问题`、`提案` 和 `备选方案` 仍然必需。

已否决记录不是当前契约。重新考虑该方案时新建 `proposed` 记录，链接原记录并说明条件变化，不把它改成 `implemented`。

仅当记录仍能避免一种可能发生且影响重大的错误时保留；理由不再防止真实误判，或方案前提已经消失时，删除整份记录并修复活动入链。不按年龄、篇幅或数量配额清理。

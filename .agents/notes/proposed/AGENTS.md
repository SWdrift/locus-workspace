# 提案记录

这里存放尚未实施或仅部分实施的提案。遵循 [决策记录规范](../AGENTS.md#文件格式)。提案在未落地时可以合理地使用将来时；`## 提案`、`## 验收标准` 和 `## 风险` 描述的是计划，不是已交付行为。

`## 提案` 写清方案组成、职责边界、迁移步骤和仍待解决的问题；确定程度不足时如实说明。`## 验收标准` 写可观察的完成状态，不写任务清单或进度百分比。`## 风险` 同时写可能出错的事项和方案有意放弃的东西。

方案落地后按[在生命周期之间移动](../AGENTS.md#在生命周期之间移动)迁移到 `implemented/`；方案被否决时迁移到 `rejected/`，在状态行写一行拒绝理由并冻结正文。过时提案按拒绝处理，不归档，也不留在 `proposed/` 冒充待办。

`proposed/` 不是任务板：进度、负责人和排期属于项目管理工具，不写入 Agent Note。

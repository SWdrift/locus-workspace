# 已实施记录

这些 Agent Note 描述已交付的决定。遵循 [决策记录规范](../AGENTS.md#文件格式)与[文档规范](../../../docs/AGENTS.md)。

## 与实际交付保持同步

路径、符号、配置键、默认值和机制变化时，在同一个变更中更新记录中的事实，不附加变更流水账。同步的是事实落点，不是决定本身。

决定被逆转或理由不再成立时，新建 Agent Note 并相互链接；不得把原记录改写成一个相反的决定。完整取代按[取代与合并规则](../AGENTS.md#何时需要写一份)处理。

## 正文与归档

必需章节为 `问题`、`决定`、`备选方案`、`后果`；不得保留 `提案`、`计划`、`迁移计划`、`验收标准` 等提案章节。普通用法、参数和接口契约已有所有者时链接过去，不复制第二份正文。

决定已完整落地、理由不太可能再指导未来工作，但记录仍有历史价值时，按[归档与删除](../AGENTS.md#归档与删除)移入 `archived/`。纯机械变更或小型 UI 调整的记录可直接删除；局部缺陷、新能力或实质行为决策不能仅因改动小就删除。

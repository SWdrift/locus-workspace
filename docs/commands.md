# 实用命令

本页登记当前可用的仓库命令：调用方式、用途与成功判据。环境前提与可运行范围见[开发与验证](development.md)，脚本实现见[维护脚本](../scripts/README.md)。

## 文档检查

| 命令 | 用途 | 成功判据 |
|---|---|---|
| `pnpm docs:check` | 检查维护范围内的 Markdown 与决策记录 | 输出 `文档检查通过：N 个 Markdown 文件。`，退出码 0 |
| `pnpm docs:test` | 验证检查器的通过和失败边界 | Node 测试全部通过，退出码 0 |
| `pnpm docs:check --root <目录>` | 对指定目录执行同一检查 | 同上；`<目录>` 必须是存在的真实目录 |

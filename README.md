# Locus Workspace

面向人与 Agent 的本地优先工作空间。Workspace 具有稳定身份，可以挂载多个本机目录，并通过统一 shell 注入 Workspace 上下文与 `locus` 命令。

当前交付 Workspace、挂载管理、统一 shell、项目模板、远程 SSH 目标与 Core 权限／凭据平面；Web 与更多 Compose 尚未交付。

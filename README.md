# Locus Workspace

面向人与 Agent 的本地优先工作空间，连接已有资源、工具与工作活动，保留外部系统的自治和事实所有权。

当前提供持久 Workspace（稳定身份与显式长期关系）与本机 Filesystem 的位置登记、单层发现、有界读取，通过项目内 DSH CLI 操作。

# Locus Workspace

面向人与 Agent 的本地优先工作空间，连接已有资源、工具与工作活动，保留外部系统的自治和事实所有权。

当前提供持久 Workspace、多位置 Filesystem、最小只读 Git、Remote Machine 登记/关联/SSH 观察、SSH/FRP Connection Profile、Gitea 仓库与 Actions Run 只读观察，以及 DSH Session 发现/关联，通过项目内 DSH CLI 操作。

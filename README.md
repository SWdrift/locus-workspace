# Locus Workspace

面向人与 Agent 的本地优先工作空间。Workspace 具有稳定身份，可以挂载多个本机目录，并通过统一 shell 注入 Workspace 上下文与 `locus` 命令。

当前交付 Workspace、挂载管理、统一 shell、项目模板与 [Locus Skill](.agents/skills/locus/SKILL.md)；Filesystem 管理、连接、密钥与 Web 尚未交付。
